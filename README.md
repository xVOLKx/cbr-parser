# <img src="images/parser.svg" width="32"> Парсер курсов валют (ЦБ РФ)

## <img src="images/features.svg" width="24"> Результат

- <img src="images/parser.svg" width="20"> В консоль выводятся первые 5 курсов
- <img src="images/parser.svg" width="20"> Все 54 курса сохраняются в файл cbr_rates.json

## <img src="images/install.svg" width="24"> Как запустить

1. Установи [Node.js](https://nodejs.org/).

2. Склонируй репозиторий:
   ```bash
   git clone https://github.com/xVOLKx/cbr-parser.git
   ```
3. Перейди в папку проекта:
   ```bash
   cd cbr-parser
   ```
4. Установи зависимости:
   ```bash 
   npm install axios
   ```
5. Запусти:
   ```bash
   node cbr_json.js
   ```
